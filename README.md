# AI Build Night

I want to build a tool for managaing the pros and cons associated with AI in education.

One example that I would be curious to explore is the idea that where in 2020 the assignment might be to compose an essay about a subject, instead, the assignment would be to explore that same idea, in conversation form with an LLM - and the result would be a link to a conversation - not a document.

The teacher can then ask that LLM about the actual conversation, or always jsut read it itself.

This isjust ONE of n example - so the project needs to model this so that as new axis, angles, vectors are added, the app can handle it effortlessly.
